# Automation Queue

High-value automation targets
- AI buy box extraction from calls, SMS, emails, and notes
- Market seeding bot that finds likely builders and developers in a new neighborhood
- Buyer matching against new properties automatically
- Quote prep assistant that assembles comps, buyer quotes, and parcel risks
- Weekly founder summary generation from pipeline and note updates
- Outlier detection on comps and quote clusters
- Automatic stale-buyer and stale-market alerts
- Test-property outreach to learn buy boxes and quotes in a new area
- Website scraping for project history, target areas, and for-sale inventory
- Quote-blast and follow-up help for uncertain areas where the team wants fast market feedback
- Live estimator support that speeds up initial operator review

Rule for automation work
- Prioritize automations that reduce founder memory dependence and save repeat time every week.
