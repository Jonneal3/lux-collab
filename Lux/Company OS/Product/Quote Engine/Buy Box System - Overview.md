# Buy Box System - Overview

Two buy box types
- System buy boxes: shared starting templates for a market or neighborhood
- Buyer buy boxes: real buyer-specific acquisition criteria

Why the system exists
- Match buyers to deals better
- Improve pricing confidence
- Keep market defaults separate from buyer-specific reality

Core rule
- Every real buyer should have an active profile, but not every profile should be treated as equally trustworthy.

System buy boxes
- Represent market defaults
- Should be seeded from comps, market knowledge, and neighborhood logic
- Should adapt at the market level over time

Buyer buy boxes
- Represent direct buyer behavior and stated preferences
- Should override system defaults where applicable
- Should evolve based on that buyer’s own behavior and quotes
