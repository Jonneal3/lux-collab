# Buy Box System - Data Model

Fields worth capturing
- Included neighborhoods or polygons
- Excluded neighborhoods or polygons
- Strategy type such as teardown, residential, commercial, or mixed
- Lot size range
- Minimum lot size
- Maximum lot size
- Dirt price per square foot range
- Per-property budget range
- Busy-road tolerance
- Flood or historic constraints if relevant
- Free-form notes about product style and edge cases
- Label or template name for operational reuse
- Area inclusions and area exclusions in structured form

Important distinction
- Dirt-price range and per-property budget are not the same thing.
- Some buyers can pay a strong dirt price but only up to a capped project size.

Long-term optional fields
- Pool-market sensitivity
- Views and topography preferences
- Corner-lot or interior-lot preference
- Build-style preference
